La commande man : votre meilleure alliée sous Linux

En découvrant Linux, je suis tombé sur une commande que je ne connaissais pas et qui est pourtant l'une des plus utiles du système : man.

man, pour manual, permet d'accéder directement à la documentation officielle des commandes Linux depuis le terminal. Plus besoin d'ouvrir un navigateur ou de chercher sur Internet. La réponse est souvent déjà disponible sur votre machine.

Afficher la documentation d'une commande

Par exemple :

man ls

Cette commande affiche le manuel complet de ls, avec sa description, ses options et des explications détaillées sur son utilisation.

Le même principe fonctionne avec la plupart des commandes Linux : 

man cp
man find
man grep
man chmod
man systemctl

C'est une ressource précieuse lorsqu'on découvre une nouvelle commande ou que l'on ne se souvient plus d'une option particulière.

Naviguer dans une page de manuel

Une fois dans une page man, voici quelques raccourcis utiles :

  • ↑ ↓ : Défilement ligne par ligne
  • PageUp / PageDown : Défilement par page
  • /mot : Recherche d'un mot
  • n : Occurrence suivante
  • N : Occurrence précédente
  • q : Quitter le manuel

Recherche dans une page man

L'équivalent du Ctrl + F de Windows dans une page man est :

/

Taper ensuite le mot recherché puis appuyer sur Entrée.

Exemple concret

Imaginons que vous utilisiez régulièrement ls, mais que vous ayez oublié comment afficher les tailles de fichiers dans un format lisible. 

man ls

Puis recherchez :

-h

Vous découvrirez notamment :

ls -lh

Cette option permet d'afficher les tailles en Ko, Mo ou Go plutôt qu'en simples octets.

Des commandes complémentaires très pratiques

Pour obtenir une description rapide d'une commande :

whatis ls

Pour afficher une aide condensée :

ls --help

Et si vous connaissez la fonction recherchée sans connaître le nom exact de la commande : 

man -k network
apropos network

Ces commandes parcourent l'index des pages de manuel et affichent les commandes en rapport avec le mot-clé recherché.

Un réflexe à adopter

Depuis cette découverte, mon premier réflexe lorsque je rencontre une commande inconnue est souvent : 

man nom_de_la_commande

La documentation est disponible immédiatement, même hors connexion, et elle est généralement plus complète et plus fiable que de nombreux tutoriels trouvés sur le web.

Si vous débutez sous Linux ou si vous souhaitez gagner en autonomie dans l'administration système, apprendre à utiliser man est sans doute l'un des meilleurs réflexes à adopter. Une simple commande qui ouvre la porte à toute la documentation du système.
