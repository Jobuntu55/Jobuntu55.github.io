Les commandes indispensables à connaître sous Linux

Maintenant que nous avons vu quelques commandes de base, il est important de connaître certains outils indispensables sous Linux. L'une des commandes les plus utilisées est grep, qui permet de rechercher du texte dans un fichier ou dans le résultat d'une commande.

grep : rechercher du texte

La commande grep permet de rechercher une chaîne de caractères dans un fichier ou dans la sortie d'une autre commande.

Syntaxe :

grep "texte" fichier.txt

Exemple :

grep "root" /etc/passwd

Affiche uniquement les lignes contenant le mot root.

Utilisation avec un pipe ( | )

On utilise souvent grep avec un pipe (|) afin de filtrer le résultat d'une commande.

Exemple :

mount | grep ext4

Affiche uniquement les lignes contenant ext4.

grep -v : exclure du texte

L'option -v signifie invert match. Au lieu d'afficher les lignes contenant le texte recherché, elle affiche toutes les autres lignes.

Exemple :

mount | grep -v tmpfs

Affiche le résultat de mount en supprimant toutes les lignes contenant tmpfs.

Autre exemple :

df -h | grep -v tmpfs

Permet d'afficher les systèmes de fichiers tout en masquant les systèmes temporaires tmpfs.

Commandes souvent combinées avec grep

  • ps aux | grep apache : rechercher un processus.
  • ls -l | grep ".html" : rechercher les fichiers HTML.
  • history | grep ssh : rechercher une commande dans l'historique.
  • env | grep PATH : rechercher une variable d'environnement.

À retenir

  • grep : rechercher un texte.
  • grep -v : exclure un texte.
  • | (pipe) : envoyer le résultat d'une commande vers une autre.
  • grep est l'une des commandes les plus utilisées pour filtrer rapidement des informations sous Linux.
