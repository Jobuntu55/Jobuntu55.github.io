Lab 01 - Installation et configuration initiale d'un serveur Debian 12

Objectif

Installer une machine virtuelle Debian 12 et la préparer pour une administration à distance.

Environnement

  • Hyperviseur : VirtualBox
  • Système : Debian 12 (Bookworm)
  • RAM : 2 Go
  • Disque : 20 Go (VDI)
  • Réseau : Accès par pont (Bridged Adapter)

Étapes réalisées

1. Création de la machine virtuelle

Création d'une VM nommée debian-lab avec :

  • 2 Go de RAM
  • 20 Go de stockage
  • Carte réseau en mode Accès par pont

2. Installation de Debian 12

Installation de Debian 12 à partir de l'image ISO officielle.

Durant l'installation, une erreur est apparue :

Bad archive mirror

Diagnostic

Le miroir Debian configuré pendant l'installation n'était pas accessible.

Solution

L'installation a été poursuivie sans utiliser de miroir réseau.

3. Première connexion

Connexion réussie avec l'utilisateur :

jonathan

Validation du bon fonctionnement du système :

hostnamectl

Résultat :

Operating System: Debian GNU/Linux 12 (Bookworm)
Kernel: Linux 6.1
Architecture: x86-64

4. Configuration du clavier

Le clavier était initialement mal configuré.

Reconfiguration du clavier en français (AZERTY) :

dpkg-reconfigure keyboard-configuration

5. Vérification du réseau

Affichage de la configuration réseau :

ip a

Adresse IP obtenue :

192.168.1.113/24

6. Test de connectivité

Vérification de l'accès Internet :

ping -c 4 8.8.8.8

Résultat :

4 packets transmitted
4 received
0% packet loss

Connexion Internet opérationnelle.

7. Correction des dépôts APT

Problème rencontré :

apt update

renvoyait une demande d'insertion du CD Debian.

Cause

Le fichier :

/etc/apt/sources.list

contenait uniquement :

deb cdrom:

Solution

Remplacement des sources locales par les dépôts officiels Debian en ligne.

8. Installation d'OpenSSH

Mise à jour des paquets :

apt update

Installation du serveur SSH :

apt install openssh-server

Objectif :
Permettre l'administration à distance du serveur.

Compétences acquises

  • ✅ Création d'une machine virtuelle VirtualBox
  • ✅ Installation de Debian 12
  • ✅ Configuration réseau
  • ✅ Diagnostic d'erreurs d'installation
  • ✅ Configuration du clavier sous Linux
  • ✅ Utilisation des commandes Linux de base
  • ✅ Gestion des dépôts APT
  • ✅ Installation et configuration du service SSH

Difficultés rencontrées

Erreur « Bad archive mirror »

Cause : Miroir Debian inaccessible.

Solution : Installation poursuivie sans miroir.

Dépôts configurés sur le CD-ROM

Cause : APT utilisait l'image ISO comme source principale.

Solution : Modification du fichier sources.list pour utiliser les dépôts officiels Debian.

Conclusion

L'installation du serveur Debian 12 a été réalisée avec succès. Le système dispose d'un accès réseau fonctionnel, d'une configuration clavier adaptée et du service SSH permettant une administration à distance. Ce laboratoire constitue une base solide pour les prochains labs (Nginx, Docker, supervision, etc.).
