mount : afficher et monter les systèmes de fichiers

La commande mount est utilisée pour afficher les systèmes de fichiers montés sur la machine Linux. Elle permet également de monter une partition, un disque ou une clé USB afin de pouvoir accéder à son contenu.

Afficher les systèmes de fichiers montés

mount

Exemple de résultat :

/dev/sda2 on / type ext4
/dev/sdb1 on /mnt type xfs
tmpfs on /run type tmpfs

On peut y voir le périphérique, le point de montage et le type de système de fichiers utilisé.

Connaître le type de système de fichiers

La commande mount permet notamment d'identifier les systèmes de fichiers :

  • ext4
  • xfs
  • btrfs
  • zfs
  • tmpfs
  • ntfs

Filtrer les résultats avec grep

Afficher uniquement les systèmes de fichiers de type ext4 :

mount | grep ext4

Masquer les systèmes de fichiers temporaires tmpfs :

mount | grep -v tmpfs

Monter une partition

Pour rendre accessible une partition ou une clé USB, il faut la monter dans un répertoire appelé point de montage. 

mount /dev/sdb1 /mnt

La partition /dev/sdb1 sera alors accessible depuis le dossier /mnt.

Démonter une partition

umount /mnt

La commande umount permet de démonter proprement une partition avant de retirer un disque ou une clé USB.

À retenir

  • mount affiche les systèmes de fichiers montés.
  • mount permet de monter une partition dans un dossier.
  • umount permet de démonter une partition.
  • mount | grep ext4 filtre les systèmes de fichiers de type ext4.
  • mount | grep -v tmpfs masque les systèmes de fichiers temporaires.
