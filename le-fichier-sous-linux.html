Consultation des fichiers

Afficher le début d'un fichier

La commande head permet d'afficher le début d'un fichier.

head fichier.txt

Afficher les 20 premières lignes :

head -n 20 fichier.txt

Afficher la fin d'un fichier

La commande tail permet d'afficher la fin d'un fichier.

tail fichier.txt

Suivre l'évolution d'un fichier de logs en temps réel :

tail -f /var/log/syslog

Informations détaillées sur un fichier

Commande stat

La commande stat affiche de nombreuses informations sur un fichier :

  • Taille
  • Permissions
  • Propriétaire
  • Dates de création et de modification
  • Numéro d'inode
stat fichier.txt

Les inodes

Un inode contient les informations d'un fichier ou d'un dossier sur le système de fichiers.

Afficher le numéro d'inode :

ls -li

Le numéro affiché correspond à l'inode du fichier. Celui-ci permet au système de retrouver l'emplacement des données sur le disque.

Types de fichiers sous Linux

La première lettre affichée par ls -l indique le type de fichier :

  • - : fichier régulier
  • d : répertoire (dossier)
  • l : lien symbolique
  • b : périphérique de type bloc
  • c : périphérique de type caractère
  • s : socket
  • p : tube nommé (pipe)

Exemple :

ls -l

Liens (Links)

Créer un lien physique

ln fichier.txt lien.txt

Les deux fichiers pointent vers le même inode.

Créer un lien symbolique

ln -s fichier.txt raccourci.txt

Le lien symbolique agit comme un raccourci vers le fichier d'origine.

Montage des systèmes de fichiers

Commande mount

La commande mount permet :

  • de voir les systèmes de fichiers montés ;
  • de connaître leur type ;
  • de monter une partition dans un répertoire afin de pouvoir accéder à son contenu.

Exemples de systèmes de fichiers :

  • ext4
  • xfs
  • btrfs
  • zfs
mount

Espace disque

Commande df (Disk Free)

La commande df affiche :

  • la taille totale des disques ;
  • l'espace utilisé ;
  • l'espace disponible ;
  • le taux d'occupation.
df

Version plus lisible :

df -h

Le paramètre -h signifie human-readable (format lisible par un humain).

Taille des fichiers et répertoires

Commande du (Disk Usage)

La commande du permet d'afficher la taille occupée par un fichier ou un répertoire.

du fichier.txt

Afficher la taille d'un répertoire de manière lisible :

du -sh dossier
  • -s : résumé uniquement
  • -h : affichage lisible (Ko, Mo, Go)
