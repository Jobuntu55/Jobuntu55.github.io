Commandes Linux à connaître absolument

Navigation

pwd

Affiche le répertoire courant.

ls

Liste les fichiers et dossiers.

ls -la

Affiche tous les fichiers (y compris cachés) avec détails.

cd dossier

Se déplacer dans un dossier.

cd ..

Remonter d'un niveau.

cd ~

Retour au dossier personnel.

Gestion des fichiers

touch fichier.txt

Créer un fichier vide.

mkdir dossier

Créer un dossier.

cp source destination

Copier un fichier.

mv ancien nouveau

Déplacer ou renommer un fichier.

rm fichier

Supprimer un fichier.

rm -r dossier

Supprimer un dossier et son contenu.

Lecture des fichiers

cat fichier.txt

Afficher le contenu d'un fichier.

less fichier.txt

Lire un fichier page par page.

head fichier.txt

Afficher les 10 premières lignes.

tail fichier.txt

Afficher les 10 dernières lignes.

tail -f log.txt

Suivre un fichier en temps réel.

Recherche

grep "texte" fichier.txt

Rechercher du texte dans un fichier.

find /home -name "*.txt"

Rechercher des fichiers.

which commande

Afficher l'emplacement d'une commande.

Processus

ps aux

Afficher les processus en cours.

ps aux | grep ssh

Rechercher les processus SSH.

top

Surveiller le système en temps réel.

kill PID

Arrêter un processus.

kill -9 PID

Forcer l'arrêt d'un processus.

Utilisateurs et permissions

whoami

Afficher l'utilisateur connecté.

id

Afficher les groupes et identifiants.

chmod 755 fichier

Modifier les permissions.

chown user:groupe fichier

Changer le propriétaire.

Réseau

ip a

Afficher les adresses IP.

ping google.fr

Tester la connectivité réseau.

ssh utilisateur@ip

Connexion distante SSH.

scp fichier user@ip:/dossier

Copier un fichier via SSH.

ss -tuln

Afficher les ports ouverts.

Système

uname -a

Informations sur le système.

df -h

Espace disque disponible.

free -h

Mémoire RAM disponible.

uptime

Temps de fonctionnement de la machine.

Archives

tar -cvf archive.tar dossier

Créer une archive.

tar -xvf archive.tar

Extraire une archive.

zip archive.zip fichier

Compresser en ZIP.

unzip archive.zip

Décompresser un ZIP.

Variables spéciales Bash

$0

Nom du script.

$1, $2, $3...

Arguments du script.

$#

Nombre d'arguments.

$*

Tous les arguments sous forme de chaîne unique.

$@

Tous les arguments séparément.

$$

PID du script courant.

$?

Code retour de la dernière commande (0 = succès).

Substitution de commande

$(commande)

Exécute une commande et récupère son résultat.

echo "Date : $(date)"

Pipes et redirections

commande > fichier

Redirige la sortie vers un fichier.

commande >> fichier

Ajoute au fichier.

commande1 | commande2

Envoie la sortie d'une commande vers une autre.

cat fichier.txt | grep erreur
