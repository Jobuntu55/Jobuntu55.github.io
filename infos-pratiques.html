Historique des commandes (History)

Réexécuter une commande

Réexécuter la dernière commande :

!!

Réexécuter une commande précise de l'historique :

!100

Exemple : exécute à nouveau la commande n°100 de l'historique.

Afficher l'historique complet :

history

Variables d'environnement

Les variables d'environnement sont des informations stockées en mémoire et utilisées par le système d'exploitation ainsi que par les applications. Elles permettent de personnaliser le comportement de Linux et des programmes.

À quoi servent-elles ?

  • Stocker des paramètres système.
  • Définir le chemin de recherche des commandes.
  • Configurer des applications.
  • Conserver des informations sur l'utilisateur connecté.
  • Partager des informations entre plusieurs programmes.

Exemples de variables courantes

  • HOME : répertoire personnel de l'utilisateur.
  • USER : nom de l'utilisateur connecté.
  • PATH : liste des dossiers où Linux recherche les commandes.
  • SHELL : shell utilisé par l'utilisateur.
  • HOSTNAME : nom de la machine.

Afficher une variable

echo $HOME
echo $USER
echo $PATH

Exemple pratique

export PRENOM="Jonathan"
echo "Bonjour $PRENOM"

Résultat :

Bonjour Jonathan

À retenir

  • export crée ou modifie une variable d'environnement.
  • echo $VARIABLE affiche son contenu.
  • env affiche toutes les variables d'environnement.
  • Les variables créées avec export disparaissent lorsque le terminal est fermé, sauf si elles sont ajoutées dans ~/.bashrc.

Répertoire /var

/var signifie Variable.

Ce répertoire contient les données qui évoluent et changent régulièrement.

Exemples courants :

  • /var/log : fichiers de journalisation (logs)
  • /var/tmp : fichiers temporaires
  • /var/cache : fichiers de cache
  • /var/lib : données utilisées par certaines applications et services

Créer ou modifier une variable

La commande export permet d'ajouter ou de modifier une variable d'environnement.

export MON_TEST="Bonjour"

Afficher la valeur de la variable :

echo $MON_TEST

Résultat :

Bonjour

Afficher les variables d'environnement

Afficher toutes les variables d'environnement :

env

Rechercher une variable spécifique :

env | grep MON_TEST

Navigation dans une ligne de commande

  • Ctrl + A : aller au début de la ligne
  • Ctrl + E : aller à la fin de la ligne
  • Ctrl + K : supprimer du curseur jusqu'à la fin de la ligne
  • Ctrl + U : supprimer du curseur jusqu'au début de la ligne

Recherche dans l'historique

Rechercher une commande déjà exécutée :

Ctrl + R

Puis saisir une partie de la commande recherchée.

Exemple :

(reverse-i-search)`man': man ls

Le terminal affiche automatiquement la dernière commande correspondante.
