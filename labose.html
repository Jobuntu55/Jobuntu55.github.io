Arborescence Linux : comprendre les principaux répertoires

Sous Linux, tout est organisé à partir du répertoire racine /. Chaque dossier possède un rôle précis dans le fonctionnement du système. Voici les répertoires les plus importants à connaître.

/bin
Contient les binaires essentiels accessibles à tous les utilisateurs (ex. ls, cp, cat).
/boot
Fichiers nécessaires au démarrage : noyau (vmlinuz), initrd et chargeur de démarrage (GRUB).
/dev
Fichiers spéciaux représentant les périphériques (disques, ports, imprimantes, etc.).
/etc
Fichiers de configuration du système et des services (ex. /etc/passwd, /etc/fstab).
/home
Répertoires personnels des utilisateurs avec leurs fichiers et préférences.
/lib
Bibliothèques partagées essentielles utilisées par les programmes de /bin et /sbin.
/lib64
Version 64 bits des bibliothèques partagées.
/lost+found
Zone où sont placés les fichiers récupérés après une réparation du système de fichiers.
/media
Points de montage automatiques des supports amovibles (clés USB, CD-ROM, cartes mémoire...).
/mnt
Points de montage temporaires pour disques, partitions ou systèmes de fichiers.
/opt
Logiciels additionnels installés en dehors du système de base.
/proc
Système de fichiers virtuel donnant des informations sur les processus et le noyau (ex. /proc/cpuinfo).
/root
Répertoire personnel de l'utilisateur root (administrateur).
/run
Informations temporaires d'exécution : PID, sockets, états des services, etc.
/sbin
Binaires essentiels destinés à l'administration du système (ex. mount, shutdown).
/srv
Données des services fournis par le système (sites web, FTP, serveurs de fichiers, etc.).
/sys
Interface entre le noyau Linux et les périphériques via un pseudo-système de fichiers.
/target
Répertoire rarement présent, utilisé par certains systèmes pour des montages spécifiques ou lors de procédures de démarrage.
/tmp
Fichiers temporaires généralement supprimés au redémarrage du système.
/usr
Programmes, bibliothèques et documentation destinés aux utilisateurs (ex. /usr/bin, /usr/share).
/var
Données variables : journaux système (logs), files d'attente, caches, bases de données et courriels.
vmlinuz
Fichier du noyau Linux compressé utilisé au démarrage du système.

Structure et répertoires Linux

Types d'utilisateurs

Dans le terminal Linux :

  • # : indique généralement que l'on est connecté en tant que root (superutilisateur).
  • $ : indique que l'on est connecté en tant qu'utilisateur standard.

Répertoire /sbin

/sbin signifie System Binaries.

Ce répertoire contient des programmes système destinés principalement à l'administration du système et au superutilisateur (root).

Exemples :

/sbin/reboot
/sbin/fsck
/sbin/ip

Répertoire /sys

Le répertoire /sys est utilisé pour les informations avancées du système Linux.

Il permet d'accéder à de nombreuses informations sur :

  • le noyau Linux ;
  • le matériel ;
  • les pilotes ;
  • les paramètres du système.

On y trouve notamment des informations et paramètres liés au noyau.

Exemple :

ls /sys

Répertoire personnel utilisateur

Sous Linux, l'équivalent du dossier AppData de Windows se trouve principalement dans le répertoire personnel de l'utilisateur :

/home/nom_utilisateur

Les fichiers de configuration cachés commencent généralement par un point :

.bashrc
.gitconfig
.mozilla

RC (Resource Configuration)

Le suffixe rc signifie généralement Run Commands ou Resource Configuration.

Il correspond à des fichiers de configuration chargés automatiquement par un programme.

Exemples :

~/.bashrc
~/.vimrc

Ces fichiers permettent de personnaliser le comportement des applications et du shell.
